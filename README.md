# Thực Đơn Dinh Dưỡng

Website HTML/CSS/JavaScript thuần, có thể chạy trên GitHub Pages.

## Chạy trên GitHub Pages

1. Tạo repository mới trên GitHub.
2. Tải lên toàn bộ file trong thư mục này, trong đó `index.html` nằm ở thư mục gốc.
3. Vào `Settings` -> `Pages`.
4. Chọn `Deploy from a branch`.
5. Chọn nhánh `main`, thư mục `/ (root)`, rồi bấm `Save`.
6. Chờ vài phút, GitHub sẽ cấp địa chỉ dạng `https://ten-tai-khoan.github.io/ten-repository/`.

## Sử dụng

- Chỉ chỉnh giá theo VNĐ/100g (hoặc VNĐ/quả đối với trứng).
- Bấm `LÊN THỰC ĐƠN` để tự động tìm khẩu phần tối ưu.
- Trứng được tính theo quy ước 2 quả = 100g.
